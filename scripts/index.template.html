About Claude mods

What is a Claude mod?

A Claude mod is a Claude Code plugin built from function hooks. It can draw a live pane, band, status line or toast inside Claude Code, or guard what Claude does. This directory also lists the wider ecosystem: plugins, skills, subagents, slash commands, hooks and MCP servers.

How do I install one?

Add the marketplace once with /plugin marketplace add {{repo}}, then install any mod by name, like /plugin install cc-arcade@{{marketplace}}. Entries outside the marketplace link to their own setup steps.

Is claudemods official?

No. It's a community project, not affiliated with or endorsed by Anthropic. The list is CC0, each linked project keeps its own license, and anyone can submit an entry.
