About Claude mods

What is a Claude mod?

A Claude mod is a Claude Code plugin built from function hooks. It can draw a live pane, band, status line or toast inside Claude Code, or guard what Claude does. This directory also lists the wider ecosystem: plugins, skills, subagents, slash commands, hooks and MCP servers.

How do I install one?

Add the marketplace once with /plugin marketplace add omarcevi/claudemods, then install any mod by name, like /plugin install cc-arcade@claudemods. Entries outside the marketplace link to their own setup steps.

How are plugins checked?

Every plugin in the marketplace is pinned to a commit we reviewed. A scan of that commit lists what it runs: shell hooks, code that runs inside Claude Code, MCP servers, and flags such as network access, running programs or skipping permission prompts. A plugin that downloads code at runtime isn't bundled unless we say why. Updates arrive as pull requests that show what changed, and every plugin is install-tested weekly.

Is claudemods official?

No. It's a community project, not affiliated with or endorsed by Anthropic. The list is CC0, each linked project keeps its own license, and anyone can submit an entry.
